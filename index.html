📖 LLY 科研脉络 · 使用指南

从左到右细分脉络 · 四象限自由推进 · 本地与 GitHub 双端同步

🧭 1. 四向白板与脉络导图
  • 四向拉线与新建：鼠标移到深色主题卡片或任务卡片时，上 / 下 / 左 / 右四边会浮现圆点；按住任意圆点拖向另一卡片即可连线，拖到空白处松手可直接在落点新建卡片，连线自动走最近的对向边。
  • 批量拖动与整组平移：按住 Shift + 拖框（或 Shift 点选）可框选多张卡片批量移动；在「全部主题总览」里，按住某个课题虚线框左上角的标题标签拖动，可带着整组卡片一起平移。
  • 三合一整理菜单（就近对齐 ▾）：默认点「就近对齐」保留你的四向摆位，只微调齐平与解重叠；点右侧 ▾ 还可选「🧲 课题块紧凑拼合」（锁住各课题内部摆位拉近间距）或「🌿 向右树状重排」，均支持「↩ 撤销排版」。单卡拖动时带极轻的 4px 参考线（按住 Alt 临时关闭）。
  • 视野与分层总览：滚轮上下平移、Ctrl + 滚轮缩放；工具栏提供「⛶ 铺满」（缩放铺满当前窗口）与「⌖ 起点」；总览下切换 2级 | 3级 | 全部 时会自动无损收紧/拉开课题间距，不改写原坐标。
  • 快捷编辑与连线标注：双击卡片标题原地改名；点击或右键任意连线可添加简短文字标注（如「失败转方案」「支撑机理」），不填则保持空白。

📋 3. 近期看板 · 📝 纯便签 · 🍅 番茄钟 · 📅 倒计日
  • 四象限看板：按 重点攻坚 / 正在推进 / 常规待办 / 已完成 展示，点左上角统计数字可单框聚焦。
  • 📝 纯便签墙与「记一笔」：右侧看板的「记一笔」默认存为暖黄色纯便签（置顶露出最新 3 条，不混入待办统计），完整列表在顶部「📝 便签」页，支持换色、置顶、原地编辑及一键「↗ 转为正式卡片」。
  • 🍅 番茄钟 & 📅 倒计日：番茄钟切页后后台持续计时并显示在标签页标题；倒计日与便签均自动同步至手机端。
☁️ 4. 无感双端同步、智能合并与 7 天备份
  • 无感拉取 + 三方智能合并：一端有改动而另一端未改时，切回窗口或点同步会静默拉取不弹窗；两端改了不同卡片/便签或电脑拖了坐标、手机改了状态时会自动合并，真冲突时提供「✨ 智能合并两端」。
  • 自动保存与 7 天备份：停手 15 秒后自动写入本地文件夹并同步 GitHub（同时自动留存本地与云端近 7 天每日备份），随时可按 Ctrl + S 立即同步。
  • 数据中心、安全与离线运行：本页面已内置全部原生 CSS、0 第三方网络依赖，断网也能完整使用；GitHub 同步请使用仅授单仓库 Contents 权限的细粒度 PAT，设备丢失或口令泄漏请立即在 GitHub 吊销。点右上角 ⚙ 数据 可管理本地文件夹、口令与 Edge 启动器。
快捷键：Ctrl+Enter 新增工作 · Ctrl+S 立即同步 · Esc 关闭弹窗
