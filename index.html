📖 LLY 科研脉络 · 使用指南

从左到右细分脉络 · 四象限自由推进 · 本地与 GitHub 双端同步

🧭 1. 脉络导图操作
  • 新建与细分：双击画布空白处新建卡片；按住卡片右侧的靛蓝圆点拖向另一张卡片建立连线，或拖到空白处松手直接新建下游细分卡片。
  • 快捷编辑：双击卡片标题原地改名；点击卡片里的「待办 / 进行 / 完成」或「+ 标签」一键切换；点右上角 ✎ 展开侧栏写备注和子步骤；右键任意卡片、连线或课题有快捷菜单。
  • 总览层级：在「全部主题」下可通过工具栏 总览：2级 | 3级 | 全部 折叠过深的细枝，点击卡片右侧的 +N 徽章可直接进入该课题查看全貌。
  • 视野控制：鼠标滚轮上下平移画布，Ctrl + 滚轮缩放，点「自动整理脉络」一键排版，点「适应视图」全景缩放到视口内。
🎨 2. 连线与日期颜色说明
连线状态（跟随下游卡片）
靛蓝流动线：下游任务正在「进行中」
森林绿实线：下游任务「已完成」
冷灰实线：下游任务处于「待办」
卡片右下角日期（二选一）
26.11.20 淡灰无底色 = 创建日期
26.11.19 红底 = 已逾期截止日
26.11.23 橙底 = 今明到期 · 蓝底 7天内 · 天蓝底 7天后
📋 3. 近期看板 · 🍅 番茄钟 · 📅 倒计日
  • 四象限看板：导图不锁死前后置，看板按 重点攻坚 / 正在推进 / 常规待办 / 已完成 分类；点左上角统计数字可单框聚焦查看。
  • 🍅 番茄钟：独立专注页，切回导图或看板时会在后台继续计时，浏览器标签页同步显示剩余时间，到点自动响柔和铃声。
  • 📅 倒计日：独立记录截稿、答辩、组会等大节点，自动随本地文件夹和 GitHub 同步到手机端。
☁️ 4. 数据安全、归档与双端同步
  • 自动防抖保存：所有改动秒存浏览器缓存，停手 15 秒后自动合并写入本地文件夹并推送 GitHub；随时可点右上角同步按钮或按 Ctrl + S 立即同步。
  • 数据与同步中心：点右上角 ⚙ 数据 可管理本地数据文件夹、配置 GitHub 同步口令、导出/导入备份及生成 Edge 桌面启动器。
  • 归档与回收站：结题或暂不做的课题可整课题 📦 归档（随时可在画布回头查看或恢复）；误删卡片可在 🗑 回收站 无损还原上下游连线。
快捷键：Ctrl+Enter 新增工作 · Ctrl+S 立即同步 · Esc 关闭弹窗
